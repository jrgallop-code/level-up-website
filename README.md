# Level Up Website

Marketing website for **Level Up — Hypertrophy Training**.

## Purpose

This repository is intentionally separate from the Level Up application repository (`forge-fitness`). It is designed for product discovery, beta acquisition, SEO/marketing pages, and eventually pricing/support/legal content without coupling those pages to the PWA application code.

## Stack

- Static HTML
- CSS
- Vanilla JavaScript
- No build step
- GitHub Pages-ready

## Local preview

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Current CTA

The primary buttons open the current Level Up PWA:

`https://jrgallop-code.github.io/forge-fitness/`

This should be replaced with the final app/domain URL when Level Up moves to its commercial domain.
